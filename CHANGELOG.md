# Changelog

All notable user-facing changes to FilmCraft are recorded here.

## Unreleased

### Added

- Timeline slider settings are saved with project views and restored with projects and recovery sessions.
- Timeline view changes are journaled for recovery without treating ordinary zoom and scroll gestures as content edits.

### Changed

- Track-header buttons stay within the visible track area, including when the track is partly clipped.

### Removed

- Dragging a track-header edge no longer resizes track height; double-clicking the header still changes its height.
